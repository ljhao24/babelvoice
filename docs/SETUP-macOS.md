# BabelVoice macOS 配置指南

BabelVoice 有两个方向：

| 方向 | 界面上的名字 | 声音怎么走 |
|---|---|---|
| 说话 | 「翻译你说的话」 | 你的麦克风 → BabelVoice 翻译 → 译音直接写入 **BabelVoice 虚拟设备** → 会议软件把麦克风设为 BabelVoice，对方听到译音 |
| 收听 | 「听懂对方在说什么」 | 采集会议音频 → 字幕窗显示译文；可选在本机播放译音 |

系统要求：macOS 14.0 及以上（说话方向的译音输出和收听方向的音频采集都依赖它）。收听方向的「收听来源」「播放对方的译音」需要 macOS 14.4 及以上；更低版本不显示这两个选项，收听固定为全部系统声音、只看字幕。

首次启动时的配置向导（安装驱动 → 授予权限 → 配置服务 → 测试说话 → 测试聆听 → 完成）会带你完成下面第 1、3 步。跳过后可以在「设置 → 高级 →「重新运行配置向导」」点「重新引导」再走一遍。

## 1. 安装 BabelVoice 虚拟驱动

macOS 不允许应用之间直接传递音频，需要虚拟驱动作为中转，会议软件才能接收译音。驱动随应用一起打包，不需要 Homebrew，也不需要另外下载。

1. 在配置向导第 1 步「安装驱动」，或在侧边栏「音频路由」页第 1 步「安装 BabelVoice 虚拟驱动」，点「安装」。
2. 系统安装器会打开，按提示完成安装，并在系统弹窗中输入开机密码。
3. 回到 BabelVoice，第 1 步会自动检测并显示「已安装」。

装好后，系统和会议软件里会出现一个名为 **BabelVoice** 的音频设备。「音频路由」页「底层链路状态」里的「BabelVoice 输出」显示「就绪」，说明系统已识别这个设备。

> 以前装过 BlackHole？两者可以共存。系统里同时有 BabelVoice 和 BlackHole 时，BabelVoice 会优先使用 BabelVoice 设备。只有 BlackHole 时，译音会写入 BlackHole，这时会议软件的麦克风要选 BlackHole，而且第 1 步仍会显示未安装。建议直接安装 BabelVoice 驱动。

## 2. 会议软件和 BabelVoice 的设备设置

在 Zoom、腾讯会议、飞书、Teams 等会议软件的音频设置里：

| 会议软件设置 | 选什么 | 为什么 |
|---|---|---|
| 麦克风 | **BabelVoice** | 对方通过它听到你说话的译音 |
| 扬声器 | 你自己的耳机或扬声器 | 你正常听会议声音 |

在 BabelVoice 的「音频路由」页：

- **第 2 步「选择麦克风」**：选你真正说话用的麦克风，默认是「使用系统默认麦克风」。列表里不会出现 BabelVoice。
- **第 3 步「选择本机播放译音的设备」**：只影响收听方向的本机播放（见第 4 节），默认是「使用系统默认输出」。列表里不会出现 BabelVoice。你说话的译音始终经 BabelVoice 送入会议，不受这一步影响。

**不需要改 macOS 的系统默认输出。** 说话方向的译音由 BabelVoice 按设备名直接写入 BabelVoice 设备，不经过系统默认输出；聚合设备、多输出设备会被跳过，建了也不起作用。按设计，你说话的译音只送进会议，不会在本机播放。

开始说话翻译：

1. 在「会议」页点「开始会议」。
2. 在「翻译你说的话」卡片点「开始翻译」，或按快捷键 **⌥ Option + Space**。按一次开始，再按一次停止；BabelVoice 窗口在前台时也可以按 Esc 停止。没有开启会议时按快捷键，会提示「请先开启会议」。
3. 快捷键可以在「设置 → 快捷键 →「开始 / 停止翻译」」点「修改」更换。

会议麦克风设为 BabelVoice 后，没有进行说话翻译时对方听不到你的原声。如果你有时想直接说会议语言，可以在「会议」页「开始会议」按钮下方的快速调整栏打开「未翻译时麦克风直通」：没有进行说话翻译时，麦克风原声会直接送入虚拟设备；开始说话翻译后自动让位给译音。收听方向不占用麦克风，开着收听也不影响直通。

## 3. 权限

| 权限 | 用途 | 在哪里授权 |
|---|---|---|
| 麦克风 | 翻译你的语音 | 配置向导第 2 步「授予权限」点「授权」；或在「会议」页第一次开始翻译时按系统弹窗允许 |
| 屏幕录制 | 捕获会议音频（macOS 把系统音频归在这项权限里） | 配置向导第 2 步点「授权」；或在「会议」页「听懂对方在说什么」卡片里点「授权」 |

快捷键不需要额外权限。

如果系统弹窗没有出现，可能之前拒绝过：

1. 打开「系统设置 → 隐私与安全性 → 屏幕录制」（麦克风在「隐私与安全性 → 麦克风」），找到 BabelVoice 并打开。
2. **完全退出** BabelVoice 再重新启动，新权限才会生效。关闭窗口只会隐藏应用，要用 ⌘Q 或菜单栏图标里的 Quit 退出。

屏幕录制权限还是不弹窗的话，可以在终端重置后重启应用，再重新授权：

```bash
tccutil reset ScreenCapture com.ljhao.babelvoice
```

「音频路由」页「底层链路状态」里的「麦克风权限」「系统音频权限」可以随时查看当前状态。

## 4. 收听方向：收听来源与播放对方的译音

在「会议」页「听懂对方在说什么」卡片点「开始聆听」，译文会显示在悬浮字幕窗里。「开始会议」按钮下方的快速调整栏里有两个独立的选项：**「收听来源」决定采集什么，「播放对方的译音」决定要不要在本机播放译音。**

### 收听来源

| 选项 | 采集什么 |
|---|---|
| 「全部系统声音」（默认） | 整机系统音频（ScreenCaptureKit），排除 BabelVoice 自己的声音。其他应用的声音（视频、音乐）也会被一起翻译 |
| 某个正在运行的应用 | 只采集这个应用的声音（Core Audio Process Tap） |

- 只看字幕时也可以选应用。选会议软件后，就只翻译会议里的声音，不会把音乐、视频一起翻译。
- 列表只显示正在运行的应用，先打开会议软件再展开下拉。
- 之前选的应用没在运行时，会显示为「应用 ID（未运行）」，例如「us.zoom.xos（未运行）」。重新选择即可。

### 播放对方的译音

- 打开后，对方语音的译音会在本机播放，使用「音频路由」第 3 步选的设备（默认是系统默认输出）。
- **必须先在「收听来源」里选一个应用**，否则这个开关是灰的、点不了。收听全部系统声音时，播放出来的译音会被重新录入，形成回环。
- 你开始说话翻译时，对方的译音会自动暂停，已经排队的也会停掉，字幕照常显示；说话翻译结束后，从下一句译音开始恢复。这样外放的译音不会被你的麦克风收进去、再翻译发进会议。开着「未翻译时麦克风直通」时不受这个保护，外放时建议戴耳机。
- 这个开关和收听来源分开保存：把来源切回「全部系统声音」，播放会自动失效并变灰；再选一个应用，之前开着的播放会自动恢复。

这两个选项都需要 macOS 14.4 及以上。快速调整栏只在「会议」页没有进行中的会议时显示，请在「开始会议」之前设置好。

## 5. 排错

### 怎么确认对方听得到

在会议软件的音频设置里把麦克风选为 BabelVoice，打开它的麦克风测试，然后在 BabelVoice 开始翻译、说一句话。会议软件里有回放或音量跳动，就说明正常。

你说话的译音只送入会议，不会在本机播放，所以自己听不到是正常的。配置向导的「测试说话」是例外：它会在本机播放一次英文译音，仅用于测试。

### 对方听不到我

- 「音频路由」第 1 步是否显示「已安装」，「底层链路状态」里的「BabelVoice 输出」是否「就绪」。
- 会议软件的麦克风是否选了 BabelVoice（只装了 BlackHole 时选 BlackHole）。
- 是否已经点了「开始翻译」或按了 ⌥ Option + Space。只「开始会议」不会开始翻译；如果需要在未翻译时传原声，打开「未翻译时麦克风直通」。
- 「音频路由」第 2 步选的麦克风是否就是你在用的那只，麦克风权限是否已授权。

### 会议软件的麦克风列表里没有 BabelVoice

- 先确认 BabelVoice「音频路由」第 1 步显示「已安装」。
- 退出会议软件再重新打开，刷新设备列表。
- 仍然没有的话，注销当前 macOS 用户再重新登录（或重启），让系统重新加载驱动。

### 「播放对方的译音」是灰的，点不了

先在快速调整栏的「收听来源」里选一个应用（通常是会议软件）。来源是「全部系统声音」时不能播放译音，否则会形成回环。

快速调整栏里根本没有「收听来源」和「播放对方的译音」：说明 macOS 低于 14.4，收听只能采集全部系统声音、只看字幕。

### 没有字幕

- 收听来源是「全部系统声音」时：检查屏幕录制权限，授权后要完全退出 BabelVoice 再启动。
- 收听来源选了应用时：确认这个应用正在运行、正在播放会议声音（显示「（未运行）」就重新选择）。也可以把来源切回「全部系统声音」对比一下。

### 本机听不到对方语音的译音

- 确认「收听来源」选了应用，并且「播放对方的译音」已经打开。来源是「全部系统声音」时，播放会自动失效。
- 确认「音频路由」第 3 步选的是你正在用的耳机或扬声器；选「使用系统默认输出」时，跟随 macOS 当前的默认输出。

### 快捷键没反应

- 先在「会议」页「开始会议」。
- 快捷键可能被其他应用占用，在「设置 → 快捷键」里换一个组合。
