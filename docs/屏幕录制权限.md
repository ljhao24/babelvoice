## macOS 屏幕录制权限

### 触发系统授权弹窗

必须调用 `desktopCapturer.getSources()`,Electron 没有 `askForMediaAccess('screen')`。
实现见 `src/main/platform/macos.ts` 的 `requestScreenCapturePermission`。
渲染层走 `window.translatorBridge.requestScreenPermission()`。

### 授权后必须重启 app

macOS 不会把新权限注入已运行进程,授权后 `Cmd+Q` 完全退出再启动。

### 排查:点了「请求权限」没弹窗

TCC 库里之前已记录拒绝。重置后重启:

```bash
# dev 模式
tccutil reset ScreenCapture com.github.Electron
# 打包后
tccutil reset ScreenCapture com.ljhao.meeting-translator
# 或全清
tccutil reset ScreenCapture
```

如果系统设置列表里出现了错误的 app(如终端),先去列表里删掉那条再 reset。

### 屏幕录制权限状态特殊

没有 `not-determined`,首次也是 `denied` —— 不要据此判定用户拒绝过,直接调 `requestScreenPermission` 让 macOS 自己决定。
